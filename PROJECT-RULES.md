# ALLI OS - Project Rules

Version: 0.1

Owner:
Tejsai (Binnu)

---

# Mission

ALLI is a completely local AI Operating System built from scratch.

The goal is to create an AI assistant that helps with:

- Semester preparation
- ECET preparation
- Learning new skills
- Programming
- Productivity
- Automation
- Creativity
- Personal knowledge management

The project should remain useful for many years.

---

# Vision

ALLI should become the first application opened after starting the computer.

Instead of opening many different applications, the user opens ALLI and manages daily work from one place.

---

# Core Principles

1. Free whenever possible.
2. Modular architecture.
3. Local-first.
4. Privacy-first.
5. Easy to extend.
6. Easy to maintain.
7. Professional code quality.

# Coding Rules

- Keep functions small.
- Write meaningful variable names.
- Add comments where needed.
- Avoid duplicate code.
- One responsibility per module.

# Version Rules

- Build successfully
- Pass testing
- Be documented
- Be committed to Git

---

# Security Rules

Never:

Delete files without confirmation.

Shutdown the computer without confirmation.

Access passwords automatically.

Execute unknown commands automatically.

Always ask for confirmation for risky operations.

---

# Performance Goals

Startup:
<10 seconds

Normal response:
<5 seconds

Memory usage:
As low as reasonably possible.

GPU should be used whenever available.
